Skopos: Learning Symbolic Execution Searcher

In preparation for FSE 2027

Which path a symbolic execution engine explores next is decided by a hand-crafted search heuristic, and no single heuristic works well across programs. Skopos learns symbolic execution searchers instead, adapting the exploration strategy to the program under analysis.

2026

Symbolon: Symbolic Execution by Learning Code Transformation

arXiv:2606.29108, submitted to S&P 2027

Symbolic execution scales poorly on real-world programs: structural patterns drive path explosion and expensive constraints, and existing program transformations are too rigid to help. Symbolon formulates transformation discovery as a search problem — learning diverse code transformations cheaply offline, distilling them into a library of agent skills, and applying them context-sensitively to repo-level targets. It improves KLEE across 16 search strategies on 32 real-world programs, raising line coverage 3.69× on average while sharply cutting memory and solver time, and has uncovered 21 previously unknown bugs in the latest Linux kernel.

Locus: Agentic Predicate Synthesis for Directed Fuzzing

48th IEEE/ACM International Conference on Software Engineering (ICSE 2026), Rio de Janeiro

Directed fuzzing must reach target states nested deep in a program, and branch distance alone poorly captures progress toward them. Locus uses an agentic framework with program analysis tools to synthesize and iteratively refine predicates that capture semantically meaningful intermediate states, verifying via symbolic execution that each predicate strictly relaxes the target so no bug-finding input is falsely rejected. It speeds up eight state-of-the-art fuzzers by 41.6× on average and has found nine previously unpatched bugs, three already acknowledged with draft patches.
