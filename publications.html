    Symbolon: Symbolic Execution by Learning Code Transformation

    Jie Zhu, Penghui Li, Zhongxuan Li, Chihao Shen, Ziyang Li, Yizheng Chen, Kexin Pei

    arXiv:2606.29108

    Symbolic execution stalls on structural patterns that real programs are full of — symbolic loops, bit-level manipulation, awkward memory access — which drive path explosion and expensive constraints. Symbolon treats the discovery of source-level code transformations as a search problem instead of relying on fixed compiler optimizations or hand-written rewrite rules, learning a library of transformations offline and then applying them context-sensitively, since whether a rewrite helps depends heavily on where it lands.

    Locus: Agentic Predicate Synthesis for Directed Fuzzing

    Jie Zhu, Chihao Shen, Ziyang Li, Jiahao Yu, Yizheng Chen, Kexin Pei

    48th IEEE/ACM International Conference on Software Engineering (ICSE 2026), Rio de Janeiro

    Directed fuzzing has to reach target states nested deep in a program, and branch distance alone is a poor measure of progress toward them. Locus uses an agentic synthesizer–validator loop to generate predicates that capture intermediate states along the way, then proves via symbolic execution that each predicate strictly relaxes the target so no bug-finding input is ever rejected. It speeds up eight state-of-the-art fuzzers by 41.6× on average and has surfaced nine previously unpatched bugs.
